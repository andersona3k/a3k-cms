      Digital — Players

      🖥️ Browser — Windows / Edge pronto

      Abra o link acima num Edge ou Chrome: aparece um código. Ative pelo painel em Playlists → sua playlist → 📺 ativar player. Clique/F11 = tela cheia. Tela dedicada: atalho msedge.exe --kiosk <link> na inicialização.

      🤖 Android — APK —
      Instalação via ADB
      1. No aparelho: Ajustes → Sobre → toque 7× em "Número da versão" (ativa o modo desenvolvedor).
      2. Ajustes → Opções do desenvolvedor → ligue Depuração USB.
      3. No PC com adb instalado, conecte o aparelho por USB e autorize no aparelho.
      4. adb install -r a3k-player.apk
      5. adb shell am start -n com.a3k.player/.PlayerActivity — ou abra o app A3K Player.
      6. O app mostra o código; ative pelo painel igual ao browser. Ele já sobe no boot e fica em tela cheia.
      Teclado conectado (teclas de função)
      • F1 — parar o player: pede a senha 102030 e fecha o app. Sem ação em 15s, a tela de senha some e a operação continua. (Reabrir o app volta a operar.)
      • F2 — gira a tela 90° no sentido horário a cada toque.
      • F3+ — a definir.
